# Plan: dalboconsultancy.com

One-page website for Dal Bo Consultancy. Content comes from [../../offer.md](../../offer.md).

## Constraints

- Keep the template's structure and layout (`local-services`, "Anchor Plumbing", MIT licence). Colours, fonts and text can change.
- Sell the services clearly and look professional.
- **No prices** on the site. **No reviews** until real clients give them. Nothing fake.
- One section at a time: spec → approve → apply → check in the browser.

## Decisions

- Icons and `og-image.png` are generated by a small Python script (Pillow + rsvg-convert) with the site fonts (Plus Jakarta Sans, Inter). Regenerate if the sentence, colours or photo change.
- The link preview only works once the site is live at dalboconsultancy.com (it uses the full URL).

- Template accent colour keeps its class name `safety` (now teal), so the template's classes don't need renaming.
